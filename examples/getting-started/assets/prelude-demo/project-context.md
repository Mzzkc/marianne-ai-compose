# Project Context

This documentation belongs to a developer-facing reference for a library the
reader already installed. They open it with a task in mind and leave as soon
as the task is done, so every page must answer "what do I type, and what will
happen" before it explains why.

- The reference lives next to the code it documents; pages are versioned with
  the library and must not describe features that are not released.
- Readers are the audience named in the score's `audience` variable. Assume
  that level and no more: do not re-teach the language, do not skip the
  library's own concepts.
- Every page ends with the next page the reader most likely needs.
- Code examples are complete enough to run as pasted; "..." is not allowed
  inside a runnable block.
