# Review Checklist

Evaluate the draft against every item. For each, record PASS or FAIL with
the evidence (quote the line or name the section).

- [ ] **Structure** — `### Overview` and `### Summary` are present; every
      outline section appears as a `###` heading, in the outline's order.
- [ ] **Audience fit** — nothing re-teaches what the named audience knows;
      nothing assumes what they do not.
- [ ] **Examples** — at least one runnable, language-tagged code block per
      section; no `...` inside a runnable block.
- [ ] **Failure modes** — each operation names what goes wrong when misused.
- [ ] **Terminology** — each term is defined once and reused verbatim.
- [ ] **Register** — no marketing words; second person, present tense.
- [ ] **Accuracy against the outline** — every Key Point in the outline is
      stated in the draft; nothing in the draft contradicts the outline.
- [ ] **Next step** — the page ends with where the reader goes next.

A FAIL on Structure, Examples or Accuracy blocks publication; the other
items are fixed in the polish pass.
